One image summing up the world's news of Thursday 19 November 2026, for
the make.fun competition `news-image-20261119`.

## The image

A newspaper front page, 1024 x 1024, built from three generated panels
plus headlines drawn in a real font (so every word is crisp):

- **Trump, Xi and Putin meet in Beijing** — the three nuclear powers hold
  a historic trilateral summit on arms control.
- **GTA VI launches worldwide** — Vice City returns; 99 on Metacritic.
- **Voyager 1 reaches one light-day** — 49 years out, still phoning home.
- **Gulf in flames** — US strikes an Iran island as Bahrain and Kuwait
  come under fire.
- **EU backs Kyiv** — a €45bn Ukraine loan, to be repaid from Russian
  reparations.
- **World court** — rules on the Myanmar genocide case over the Rohingya.

## The program

`main.py` (Python 3.13, standard library only) copies `entry.png` to
`/output/entry.png`. It runs twice and writes the same bytes both times.
No network.

Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
